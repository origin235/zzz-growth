# 绝区零养成助手

单文件网页版《绝区零》养成电量计算器：等级 / 技能 / 核心技 / 音擎材料一次算清，支持多角色、按属性与特性分类统计。纯前端实现，数据存在浏览器本地（localStorage），不需要服务器，可直接部署到 GitHub Pages。

## 在线使用

部署到 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

手机和电脑浏览器都能直接打开，所有数据只保存在本机浏览器里，不上传任何服务器。

## 本地运行

不需要构建工具，两种方式任选：

1. 直接双击 `index.html` 用浏览器打开；
2. 或在本目录起一个静态服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 功能

- **计算器**：单个代理人 1→60 全满的材料与电量，属性 / 特性 / 音擎特性三组下拉，结果可一键写入养成计划
- **计划**：最多 8 名角色，默认 1 名，卡片式管理；手填数字、核心技 A–F 点选、技能按具体名称（普攻 / 闪避 / 支援 / 特殊技 / 终结技）
- **两个模版**：通用模版（60 / F / 60，普攻 11、闪避 7、支援 7、特殊技 11、终结技 12）与满级模板，都只改目标、不动当前；另有「不含音擎」开关
- **缺口**：填入当前库存自动折算缺口与电量；丁尼、高维数据、周本材料、仓鼠笼为单等级输入
- **数据**：五张养成数据表 + 属性 / 特性 / 音擎特性对照清单，全部只读
- **分类统计**：技能芯片按属性分（烈霜沿用冰结芯片），认证章与音擎突破件按特性分；同属性、同特性自动合并，不同则分别出账

## 计算口径

- 经验按官方分段累计、段内线性估算；突破 / 技能 / 核心 / 音擎按里程碑累计表取差值
- 等效持有：紫 + 蓝 / 3 + 绿 / 9（经验书为 / 5、/ 30）
- 电量 = 数量 × 单局电量 ÷ 单局产出；缺口页按单材料局数向上取整后再合计
- 单局高维产出按 5 个计；每日自然恢复 240 + 咖啡 80 = 320 电量
- 单角色 1→60 全满约 10,597 电量 / 33.1 天；零库存缺口约 10,720 电量 / 33.5 天

掉落参数（单局产出、电量等）都可以在计算器页「电量与掉落参数」里自行调整。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（不要勾选 README / .gitignore，保持空仓库）；
2. 把本目录推上去：

```bash
git init
git add .
git commit -m "绝区零养成助手 · 网页版"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

3. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main` / 根目录 `(root)`，保存后等一两分钟即可访问。
