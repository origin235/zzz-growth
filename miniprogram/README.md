# 绝区零养成助手 · 微信小程序

把飞书表格《绝区零养成电量计算器》做成的微信小程序工程。四个页面分别对应原表的四个子表，计算口径与原表一致（已逐项核对：单角色满级 10,597 电量 / 33.1 天；缺口 10,720 电量 / 33.5 天）。

## 一、怎么跑起来

1. 电脑安装 **微信开发者工具**（稳定版即可）。
2. 打开开发者工具 → 选择「导入项目」→ 目录选本文件夹 `zzz-growth`。
3. AppID 处选「测试号」，或填入你自己的小程序 AppID（没有就点「注册」按引导申请，个人也能免费注册）。
4. 点「编译」，模拟器里就能看到四个页面。

> `project.config.json` 里的 `appid` 目前写的是 `touristappid`（游客模式）。要**真机预览**或**上传发布**，必须换成你自己的 AppID，否则真机调试会失败。

## 二、页面与功能

| 页面 | 对应原表 | 功能 |
| --- | --- | --- |
| 计算器 `pages/calc` | 养成计算器 | 设定单角色的等级 / 核心 / 5 个技能 / 音擎目标，实时算出材料总量、折算电量、天数、以太电池数；可展开调整掉落参数 |
| 计划 `pages/plan` | 角色养成计划 | 默认 1 名角色，用「＋ 添加养成角色」增到最多 8 名（卡片右上角 × 可移除），逐卡编辑目标（数字直接填写、核心技点选 A~F），自动汇总全队材料与电量、天数；每张卡提供「通用模版」「满级模板」「不含音擎」「重置」 |
| 缺口 `pages/gap` | 资源缺口 | 填手上材料（按颜色分档：紫 / 蓝 / 绿），自动扣减、折算还需刷取多少电量 |
| 数据 `pages/data` | 数据表 | 只读展示经验曲线、突破、技能、核心、音擎五张数据表 |

进度、参数、计划、库存全部存在手机本地（`wx.setStorageSync`），关掉小程序再进不丢。

### 计划页的编辑方式

- **属性 / 特性 / 音擎特性**：三组下拉，取值按米游社官方口径（详见第五节）。属性决定技能芯片，特性决定等级突破认证章，音擎特性决定音擎突破件；切换特性时，若音擎特性还没单独改过，会跟着一起变。
- **等级 / 技能 / 音擎**：直接点输入框填数字，只接受数字；等级与音擎范围 1–60、技能 1–12；超出上限立刻改回上限，低于下限在失焦时修正为 1。
- **核心技**：点一下弹出 A~F 列表选择，左侧为「当前」，右侧为「目标」。

### 两个模版

- **通用模版**：等级 60 · 核心技 F · 音擎 60 · 技能 普攻 11 / 闪避 7 / 支援 7 / 特殊技 11 / 终结技 12；单角色约 7,928 电量、约 24.8 天。
- **满级模板**：等级 60 · 核心技 F · 音擎 60 · 五项技能全 12。

两个模版**都只改「目标」，不动「当前」**，方便按现有进度算材料。

### 角色数量

- 首次进入只有 1 名角色；点底部「＋ 添加养成角色」追加，最多 8 名，达到上限后按钮提示「已达上限 8 名」
- 新增的角色默认套用**通用模版**的目标（当前仍是 1），进来就能看到预计消耗，再按需改
- 名下有 2 名以上角色时，卡片右上角出现 ×，可移除该角色
- 「清空全部角色」会回到只剩 1 名、全部为未养成状态

### 不含音擎

模板区还有一个「不含音擎」开关：点一下常亮（表示这个角色不养音擎），再点取消。

- 开启时会把音擎目标压回当前值（即 1→1），该角色不再计入音擎材料与电量
- 开启状态下点任意模板，都只改等级 / 核心技 / 技能，**音擎项保持不动**
- 关闭时直接把音擎目标设为 60（当前等级不动）

### 模版高亮

「目标」正好等于某个模版的全部条件时，该按钮高亮（荧光黄）；手动改过任意一项后高亮自动消失，不会误标。

## 五、计算口径

- **经验**：官方分段累计，段内线性估算（20 级 3 万 / 30 级 9 万 / 40 级 22.5 万 / 50 级 45 万 / 60 级 90 万）。
- **突破**：里程碑 20/30/40/50/60，认证章 4/32/30，丁尼合计 80 万。
- **技能**：5 个技能分别按累计表做差值；全 12 级合计基础 25 / 进阶 75 / 特化 250 / 仓鼠笼 5 / 丁尼 250 万。
- **核心**：A→F 高维 60（单局 5 个、40 电量/局）/ 周本 9 / 丁尼 40.5 万。
- **音擎**：按 20/30/40/50/60 里程碑累计（中间等级取上一里程碑，与原表的 VLOOKUP 取法一致）。
- **折算电量** = 数量 × 单局电量 ÷ 单局产出；仓鼠笼、周本素材不计电量。
- **缺口电量** = 向上取整(缺口 ÷ 单局产出) × 单局电量（界面上不再展示局数）。
- **持有折算**：分三阶的材料（经验、认证章、技能芯片、音擎模块/部件）按「等效持有 = 顶 + 中/3 + 低/9」折算（经验为 /5、/30）；**丁尼、高维数据、周本材料、仓鼠笼只有单一等级，只填一个持有数量，直接与需求相减**。

## 六、要改数据 / 改文案

- 所有数值表都在 `utils/data.js`：`EXP` / `BREAK` / `SKILL` / `CORE` / `ENGINE` / `PARAMS`。改这里，四个页面全部同步。

- 配色与通用样式在 `app.wxss`（黑底 + 荧光黄 #d9ff3f）。

## 八、说明

- 小程序没有开放「猜你喜欢」之外的运营能力，本工程是纯前端本地计算，不联网、不需要服务器、不收集数据。
- 想在手机上先看效果：同目录外的 `绝区零养成助手-手机预览版.html` 是同款逻辑的单文件预览，直接用手机浏览器打开即可。
